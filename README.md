# React Classroom — 3:00 Batch

Multiple React practice applications covering reusable components, forms, user lists and loading behavior.

## Project structure

- `eshop/`
- `flipcart/`
- `frontend/`

## Getting started

```bash
git clone https://github.com/JAYANTI-THAKOR-941/REACT-3-00-TO-4-00.git
cd REACT-3-00-TO-4-00
```

Enter the desired application folder, run `npm install` and `npm run dev`. Each application has its own dependency manifest.
